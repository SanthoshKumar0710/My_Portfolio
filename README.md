## 🛠️ Technology Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Custom AI/ML Design Tokens
- **Motion & Physics**: Framer Motion
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **Graphics**: HTML5 Canvas (Scrollytelling & 3D Neural Nodes)

## 🚀 Running Locally

### Prerequisites
- Node.js 18.17+ or higher
- npm

### Installation & Execution

```bash
# Navigate to the project directory
cd Personal-portfolio-main/Personal-portfolio-main

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
